# Email subjects

Paste each subject into Supabase → Authentication → Emails → Templates, together
with the matching HTML file from this folder.

| Supabase template | Subject | File |
|---|---|---|
| Confirm signup | Your Spinning Top account code | `confirm-signup.html` |
| Reset password | Reset your Spinning Top password | `reset-password.html` |
| Change email address | Confirm your new email address | `change-email.html` |
| Magic link (used for sign-in codes) | Your Spinning Top sign-in code | `magic-link.html` |
